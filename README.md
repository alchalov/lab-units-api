**LabUnits API** — небольшой REST-сервис на FastAPI, который переводит результаты
лабораторных анализов между **единицами СИ** (ммоль/л, мкмоль/л, г/л) и
**традиционными единицами** (мг/дл, г/дл, мкг/дл).

> Это учебный проект курса "Инфраструктура и администирование" (Магистратура ПРИНТ, НИУ ВШЭ)
> Сервис не является медицинским изделием и не предназначен для клинических решений.

## 🎯 Для кого и зачем

В России и Европе результаты анализов выдают в единицах СИ, а в американских
руководствах, статьях и калькуляторах часто используются традиционные единицы.
Сервис помогает быстро сопоставить значения:

- 👩‍⚕️ **врачам и студентам-медикам** — при чтении зарубежных статей и рекомендаций;
- 🧑‍🔬 **сотрудникам лабораторий** — при сверке результатов с данными из других систем;
- 💻 **разработчикам медицинских систем** — как простой API для пересчёта.

## ✨ Возможности

- 📋 справочник из 9 биохимических и гематологических показателей;
- 🔄 перевод в обе стороны: СИ → традиционные и обратно;
- 🛡️ проверка входных данных: отрицательные значения и неизвестные показатели отклоняются;
- ⚙️ настройки через переменные окружения;
- 📝 журнал событий: запуск, пересчёты, ошибки;
- ✅ 20 автоматических тестов и CI в GitHub Actions.

## 📋 Поддерживаемые показатели

Правило пересчёта: **традиционные единицы = значение в СИ × коэффициент**.

| Код | Показатель | Единица СИ | Традиционная единица | Коэффициент |
|---|---|---|---|---:|
| `glucose` | Глюкоза | mmol/L | mg/dL | 18.02 |
| `cholesterol` | Холестерин общий | mmol/L | mg/dL | 38.61 |
| `triglycerides` | Триглицериды | mmol/L | mg/dL | 88.5 |
| `creatinine` | Креатинин | umol/L | mg/dL | 0.0113 |
| `uric_acid` | Мочевая кислота | umol/L | mg/dL | 0.0169 |
| `bilirubin` | Билирубин общий | umol/L | mg/dL | 0.0585 |
| `calcium` | Кальций общий | mmol/L | mg/dL | 4.0 |
| `iron` | Железо сывороточное | umol/L | ug/dL | 5.587 |
| `hemoglobin` | Гемоглобин | g/L | g/dL | 0.1 |

Источник коэффициентов: [Labcorp — SI Unit Conversion Table](https://www.labcorp.com/resource/si-unit-conversion-table).
Для мочевой кислоты коэффициент пересчитан на мкмоль/л (16.9 / 1000),
для гемоглобина следует из определения (1 г/л = 0,1 г/дл).

## 🔌 API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/` | Приветствие и ссылка на документацию |
| GET | `/health` | Проверка работоспособности → `{"status": "ok"}` |
| GET | `/version` | Название и версия сервиса |
| GET | `/analytes` | Список всех показателей |
| GET | `/analytes/{code}` | Карточка показателя (регистр не важен) |
| GET | `/convert/{code}?value=…&to=…` | Пересчёт значения |

Параметры `/convert/{code}`:

| Параметр | Обязательный | Значения | По умолчанию |
|---|---|---|---|
| `value` | да | число ≥ 0 | — |
| `to` | нет | `conventional` — в традиционные, `si` — в СИ | `conventional` |

Пример запроса и ответа:

```bash
curl "http://127.0.0.1:8000/convert/glucose?value=5.5"
```

```json
{
  "code": "glucose",
  "name": "Глюкоза",
  "input": {"value": 5.5, "unit": "mmol/L"},
  "result": {"value": 99.11, "unit": "mg/dL"},
  "factor": 18.02
}
```

Коды ответов:

| Код | Когда |
|---|---|
| 🟢 `200` | Запрос выполнен |
| 🟠 `404` | Показатель с таким кодом не найден |
| 🔴 `422` | Ошибка в параметрах: нет `value`, `value < 0`, неверное `to` |
